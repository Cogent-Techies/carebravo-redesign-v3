# /images

Every slot on the site already points at a file in this folder (`/images/<name>.jpg`) and at `/og/<page>.jpg` for the social cards.
Drop the generated files in with exactly those names and nothing in the HTML changes. Until a file lands, the slot shows the
gradient frame with its caption (the `<img>` removes itself on a 404). The complete list — filename, page, section, aspect,
pixel size, alt text and generation prompt — is in `IMAGE-SHOT-LIST.md` at the site root.

Rules (file 17 v2.1 and the 15 Sep 2026 rulings): every still is generated and art-directed to the one canon; no stock; no real
customer, caregiver or client; no recognisable faces; no screens or UI; no text baked in. Keep alt text as written — it is a caption.
